# Project Idea

Arcade Alchemy cohort LLM cost support

### Project Submitted By

Dekan / duckanbro. RIP Steward prepares this draft as facilitator.

## Summary

Request a flat contribution of **100 WXDAI each** for ECWireless, Santiago, and Dekan (**300 WXDAI total**) from the RaidGuild DAO treasury to help offset LLM token costs incurred while building games during the Arcade Alchemy cohort. This is cost support without itemized expense reimbursement.

The [cohort page](https://portal.raidguild.org/cohorts/arcade-alchemy-old-mechanics-new-tools) is the reference for the cohort and related work. Dekan [reported on November 4, 2026 that Demo Day was complete](https://discord.com/channels/684227450204323876/1567199272124813503/1567637637941170297); this is a participant report, not an independently verified completion assessment.

## Why should we build this?

The proposer seeks to supplement participants' LLM costs for their game-building experiments. This draft makes no claim about measured costs, return on investment, or community consensus.
